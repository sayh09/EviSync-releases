# Gestord Desktop Releases 🚀

Repositorio oficial de distribución pública de versiones ejecutables y actualizaciones automáticas de **Gestord Desktop** (Windows y macOS).

---

### 📥 Descargas Oficiales
Puedes descargar la versión más reciente directamente desde la sección de [Releases](https://github.com/sayh09/gestord-releases/releases).

* **Windows:** `.msi` / `.exe` (Instalador x64)
* **macOS:** `.dmg` (Universal para Apple Silicon M1/M2/M3/M4 e Intel)

---

### 🔄 Actualizaciones Automáticas
La aplicación de escritorio Gestord utiliza este repositorio para verificar, descargar e instalar automáticamente nuevas actualizaciones en segundo plano.
